# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). Everyone who takes part in its issues, pull requests and discussions is expected to keep to it: be kind, assume good faith, and accept that people see things differently. Harassment of any kind isn't tolerated.

## Reporting

If someone's behavior troubles you, open a [private contact request](https://github.com/plexxed/claude-desktop-account-switcher/issues/new?template=private_contact.yml), with no details in it, and a maintainer will reply with a private way to talk. Content that breaks GitHub's own rules can also be reported to GitHub directly, with **Report content** in the comment's menu. Every report is read and kept confidential. The maintainers decide what follows as the Covenant's [enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines) describe, from a private word up to a ban from the project.
